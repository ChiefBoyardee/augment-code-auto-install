# Changelog

## [Deprecated] — 2026-09-09

This project is **deprecated and unmaintained**.

Augment Code has sunset its Visual Studio Code / Cursor IDE extension and moved to cloud / CLI tooling. This repository’s primary purpose was auto-installing and updating that extension, so continued use is not recommended.

See the README deprecation notice for uninstall steps and migration pointers (e.g. `@augmentcode/auggie`).
